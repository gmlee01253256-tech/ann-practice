인공신경망 연비 예측 실습

데이터를 넣고 학습 시작을 누르면 다층 신경망(MLP)이 브라우저 안에서 순전파 → 역전파 → 경사하강법을 반복하며 학습합니다. 학습이 끝나면 다중 선형회귀와 성능을 비교하고, 새 값을 넣어 예측할 수 있습니다.

데이터 입력

쉼표나 탭으로 구분합니다. 글자로 된 열(예: 제조 지역)은 원-핫 인코딩으로 바꿔서 입력에 씁니다.

신경망 설정

쉼표로 층을 나눕니다. 예) 16, 8 = 은닉층 2개, 32 = 은닉층 1개

신경망 구조

학습 손실 변화

표준화된 값 기준 MSE (로그 스케일). 검증 손실이 더 줄지 않으면 조기 종료하고, 검증 손실이 가장 낮았던 epoch의 가중치를 씁니다.

성능 비교

모델R²RMSEMAE
학습이 끝나면 결과가 나옵니다.

R²는 1에 가까울수록, RMSE와 MAE는 작을수록 정확합니다. 두 모델은 같은 학습·테스트 데이터를 씁니다.

실제값 vs 예측값

점이 빨간 점선(y = x)에 가까울수록 정확한 예측입니다.

값 예측하기

데이터: Quinlan, R. (1993). Auto MPG [Dataset]. UCI Machine Learning Repository. · 신경망과 그래프 모두 외부 라이브러리 없이 JavaScript로 직접 구현했습니다.
